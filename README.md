# Personal Finance API

Backend REST API for managing personal finances.

## Tech Stack

- Python 3.12+
- FastAPI
- Uvicorn
- Poetry

## Features

- Health check
- Authentication (planned)
- Accounts (planned)
- Transactions (planned)
- Budgets (planned)
- Analytics (planned)

## Installation

Install dependencies:

```bash
poetry install
```

Run development server:

```bash
poetry run uvicorn app.main:app --reload
```
